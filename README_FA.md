# 📊 دیتاست

برای این پروژه از دیتاست **GTSRB** استفاده شده است.

این دیتاست شامل **۴۳ کلاس مختلف از علائم راهنمایی و رانندگی** است.

نمونه‌هایی از کلاس‌ها:

- Speed limit
- No passing
- Stop
- Yield
- No entry
- Road work
- Traffic signals
- Pedestrians
- Keep right
- Keep left
- Roundabout mandatory

کلاس‌های مختلف به‌صورت مستقل در مسئله طبقه‌بندی در نظر گرفته شده‌اند.

# 🧹 1. پاک‌سازی و بررسی داده‌ها

در مرحله آماده‌سازی داده، تصاویر بررسی شدند تا داده‌های نامعتبر وارد فرآیند آموزش نشوند.

موارد بررسی‌شده شامل:

- قابل خواندن بودن تصاویر
- صحت فایل‌های تصویری
- وجود تصاویر خراب یا غیرقابل استفاده
- صحت برچسب‌ها
- ساختار کلاس‌ها

تصاویر غیرقابل استفاده در صورت شناسایی از فرآیند آموزش حذف شدند.

---

# 📐 2. تغییر اندازه تصاویر

برای اینکه تمام تصاویر ورودی ابعاد یکسانی داشته باشند، تصاویر قبل از ورود به شبکه عصبی به اندازه مشخص تبدیل شدند.

این کار باعث می‌شود مدل تمام نمونه‌ها را با یک ابعاد ورودی ثابت دریافت کند.

---

# ⚖️ 3. Normalization

پس از Resize، مقادیر پیکسل‌های تصاویر Normalize شدند.

برای مدل‌های Transfer Learning از مقادیر Normalization مناسب مدل‌های ازپیش‌آموزش‌دیده استفاده شد.

هدف از این مرحله ایجاد ورودی پایدارتر برای شبکه عصبی و کمک به فرآیند آموزش است.

---

# 🔄 4. Data Augmentation

برای افزایش تنوع داده‌های آموزشی و کاهش Overfitting از Data Augmentation استفاده شد.

روش‌های مورد استفاده شامل:

- Rotation
- Crop
- تغییر روشنایی
- Flip

بودند.

در مورد Flip افقی، به دلیل اینکه جهت بعضی علائم اهمیت دارد، این روش با احتیاط استفاده شد تا باعث ایجاد نمونه‌های نامعتبر نشود.

# 📚 5. تقسیم داده‌ها

داده‌ها به سه بخش تقسیم شدند:

```text
Training
Validation
Test
```

### Training

برای آموزش مدل استفاده شد.

### Validation

برای بررسی عملکرد مدل در زمان آموزش و انتخاب بهترین checkpoint استفاده شد.

### Test

برای ارزیابی نهایی مدل روی داده‌هایی که در آموزش استفاده نشده‌اند به کار رفت.

# ❌ 12. تحلیل خطا

مدل ResNet18 روی مجموعه آزمون شامل **۵۸۸۲ تصویر** به Accuracy برابر با **99.97%** دست یافت.

در مجموع تنها **۲ نمونه** به‌اشتباه طبقه‌بندی شدند.

### خطای اول

```text
کلاس واقعی:
Speed limit (100 km/h)

پیش‌بینی:
Speed limit (120 km/h)

تعداد:
1
```

کلاس 100 km/h دارای Recall برابر با حدود **99.54%** و کلاس 120 km/h دارای Precision حدود **99.53%** بود.

این نشان می‌دهد که یک نمونه از علائم محدودیت سرعت 100 کیلومتر بر ساعت با کلاس 120 کیلومتر بر ساعت اشتباه شده است.

### خطای دوم

```text
کلاس واقعی:
No vehicles

پیش‌بینی:
No passing for vehicles over 3.5 t

تعداد:
1
```

Recall کلاس `No vehicles` حدود **98.95%** و Precision کلاس `No passing for vehicles over 3.5 t` حدود **99.67%** بود.

بنابراین این خطا نیز مربوط به یک نمونه از کلاس `No vehicles` بوده است.

در مجموع، خطاهای باقی‌مانده بسیار محدود بوده‌اند و بیشتر در میان کلاس‌هایی مشاهده شده‌اند که از نظر ظاهری شباهت بیشتری دارند.

# 🖥️ 14. تست مدل با Streamlit

برای آزمایش مدل نهایی یک رابط ساده با **Streamlit** ساخته شده است.

کاربر می‌تواند یک تصویر از علامت راهنمایی و رانندگی را وارد کند و مدل:

1. تصویر را دریافت می‌کند.
2. تصویر را Preprocess می‌کند.
3. آن را به ResNet18 می‌دهد.
4. کلاس پیش‌بینی‌شده را نمایش می‌دهد.
5. نام فارسی علامت را نمایش می‌دهد.
6. میزان اطمینان مدل را نمایش می‌دهد.
7. سه پیش‌بینی برتر را نشان می‌دهد.

اجرای برنامه:

```bash
python -m streamlit run streamlit_app.py
```
